# SwiftUI View Rules
- Light theme only — background is #FAFAF8, cards are #FFFFFF
- Scripture text uses serif font (Georgia or .serif), never system sans-serif
- Use SF Symbols for all icons — filled for active states, outline for inactive
- Cards: 12px corner radius, subtle shadow (0 2px 8px rgba(0,0,0,0.06)), 16px padding
- Spacing uses 4px grid: 4, 8, 12, 16, 24, 32, 48
- Reference @docs/design-system.md for full color and typography specs
