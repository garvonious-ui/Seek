# Card Template Rules
- All templates render at 1080x1920 (9:16 IG story ratio)
- Verse text auto-sizes to fit — minimum 16pt, maximum 32pt
- Always include scripture reference below verse text
- App watermark in bottom corner — small, semi-transparent
- Templates marked isPremium:true get a lock icon overlay for free users
- Test each template with short verses (Psalm 23:1) AND long passages (Romans 8:28-39)
- Reference @docs/design-system.md for font and color specs
