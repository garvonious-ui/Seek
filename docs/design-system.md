# Design System

## Theme: Light, Clean, Reverent but Modern

## Color Palette — Gold + Soft Sage
| Token | Hex | Usage |
|-------|-----|-------|
| Gold | #CDA349 | Warm gold — faith, warmth, premium feel |
| Light Gold | #EDD99A | Lighter gold for backgrounds, highlights |
| Sage | #5B7B5E | Primary sage green — earthy, grounding, approachable |
| Mid Sage | #8AAF8D | Lighter sage for hover/active states |
| Background | #FAFAF6 | Warm off-white |
| Surface | #FFFFFF | Cards, sheets, modals |
| Text Primary | #1A1A1A | Near-black for readability |
| Text Secondary | #6B7280 | Gray for supporting text |
| Text Tertiary | #9CA3AF | Light gray for timestamps, captions |
| Success | #4CAF50 | Streak milestones, completions |
| Warning | #F59E0B | Streak at risk |
| Divider | #E5E7EB | Subtle line separators |

## Typography
- **Headlines:** SF Pro Display — Semibold (system, no bundle cost)
- **Body text:** SF Pro Text — Regular
- **Scripture text:** Georgia or a bundled serif font (New York if available) — scripture should feel distinct from UI text
- **Card scripture:** 2-3 bundled fonts per template category (e.g., Playfair Display for elegant, Lora for classic)

## Spacing System
4px base grid: 4, 8, 12, 16, 24, 32, 48

## Corner Radius
- Cards: 12px
- Modals/sheets: 16px
- Buttons: 24px
- Avatars: full-round

## Shadows
Minimal — soft drop shadow on cards only: `0 2px 8px rgba(0,0,0,0.06)`

## Component Patterns
- **Cards:** White surface, 12px radius, subtle shadow, 16px internal padding
- **Scripture display:** Serif font, slightly larger size, generous line height (1.6), left-aligned
- **Buttons:** Primary = filled blue, Secondary = outlined, Tertiary = text-only
- **Chat bubbles:** User = right-aligned blue, AI = left-aligned light gray surface
- **Tab bar:** 3 tabs — Home (house icon), Chat (message icon), Library (bookmark icon)
- **Empty states:** Soft illustration + encouraging text + CTA button

## Iconography
SF Symbols (system icons) — consistent weight, filled style for active tab, outline for inactive

## Motion
Subtle — spring animations on card transitions, fade-in for content loading, no aggressive bounces

## Design References (for vibe, not copy)
- Headspace (clean, calming, great onboarding)
- Glorify (faith-specific, modern, good card designs)
- Day One journal app (clean journaling feel)
- Apple Health (clean stat presentation)
